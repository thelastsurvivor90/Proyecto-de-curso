## Descripcion
Sistema de compresion de imagenes basado en Descomposicion en Valores Singulares (SVD)
que demuestra aplicaciones practicas del algebra lineal en procesamiento de imagenes.

## Caracteristicas
- Compresion ajustable por valores singulares
- Metricas de calidad (PSNR, MSE)
- Visualizaciones interactivas
- Analisis de relacion compresion-calidad
